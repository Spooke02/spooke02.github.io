Track membership renewals in Excel

Know who is about to expire before they do, with end dates and a status that update by themselves.

1. One sheet to start

Columns: A member ID, B name, C phone (optional), D plan, E start date, F months paid, G fee paid. Then three formula columns: H end date, I days left, J status.

2. The formulas

For row 2 (start date in E2, months paid in F2):

H2 End date:   =EDATE(E2, F2)
I2 Days left:  =H2-TODAY()
J2 Status:     =IF(I2<0, "Expired", IF(I2<=7, "Expiring soon", "Active"))

Change 7 to the number of days of warning you want. Add conditional formatting so Expired is red and Expiring soon is amber.

3. Renewals

  • When someone renews, set a new start date (or add a new row if you want a history).
  • Sort by days left to see the next renewals first.
  • Count each status with =COUNTIF(J:J,"Expiring soon").
  • Keep members' details private.
